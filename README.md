# Photography

## Project Description

This project was created as part of a web development assignment to demonstrate the use of HTML, CSS, Git, and GitHub. The website showcases a collection of favorite photographs, introduces my passion for nature photography, and provides visitors with information about my photography journey.



---

##  Features

- Responsive navigation bar
- Sticky navigation bar
- Attractive homepage with a hero section
- About Me section
- Nature photography gallery
- Photography interests and workflow
- Contact form
- Responsive design for desktop and mobile devices
- Custom CSS styling with hover effects and animations
